# bogomolka — маленькая интернет-студия

Интерактивный сайт графического дизайнера: рабочий стол с предметами, фотобудка, общая стена дня, архив-календарь, игра про жизнь дизайнера, коллекция фигурок и портфолио.

Адрес сайта на GitHub Pages: **https://bogomolkakaka.github.io/bogomolkakaka/**

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Рабочий стол** (главная) | Предметы на синем коврике ведут в разделы, их можно двигать мышкой (место запоминается). Живое превью сегодняшней стены, календарь с настоящей датой, мини-игра на экране консоли, записка со случайными фразами. |
| **PHOTO BOOTH** | Камера компьютера или телефона, 8 фильтров на WebGL в реальном времени (+ «без фильтра»), зеркало, переключение камер, отсчёт 3-2-1, четыре кадра, 6 рамок, стикеры и надписи (двигать, вращать, масштабировать), скачивание PNG, «Поделиться» на телефоне, пересъёмка, загрузка готовых фото, если камеры нет, публикация на стену. Фото не покидают браузер, пока человек сам не нажмёт «Put on today’s wall». |
| **TODAY’S WALL** | Общий холст: записки разных цветов, анонимные «шёпоты», рисование тремя кистями, стикеры, картинки, фотополоски, медали из игры. Свои элементы можно двигать, вращать, масштабировать и удалять (и мышкой, и с клавиатуры). Вопрос дня. Новые элементы появляются у всех без перезагрузки. Кнопка «пожаловаться». В полночь по времени студии стена уходит в архив и открывается новая. |
| **TIME CAPSULE** | Календарь: у каждого дня маленькое превью коллажа. Переключение месяцев и лет, архивные стены открываются только для просмотра. |
| **DESIGNER RUN** | Платформер на canvas: 3 уровня (THE BRIEF, THE DEADLINE, FINAL FINAL V7), монетки, правки клиентов (их можно лопать прыжком сверху), 6 навыков с эффектами, 3 жизни, чекпоинты, GAME OVER, RESTART, экран победы и медаль на стену. Клавиатура и сенсорные кнопки, звук выключается в панели снизу. |
| **LITTLE OBJECTS** | Полка с фигурками, ценники со статусами, вторая фотография при наведении, карточка с галереей, цветами и деталями, запрос на покупку. Редактирование в режиме «Студия». |
| **MY STUFF** | Разбросанные постеры, развороты, полароиды и папки по категориям, отдельная страница проекта. Редактирование в режиме «Студия». |
| **Studio admin** | Вход для хозяйки, модерация стены (жалобы, скрыть/удалить, любой день), вопросы дня, свои стикеры, включение рамок фотобудки, контакты и часовой пояс. |

Пасхалки: наберите на клавиатуре `kerning` или ↑ ↑ ↓ ↓ ← → ← → B A. И постучите по полке с фигурками.

## Два режима работы

**Демо-режим** включается сам, пока база не подключена. Всё открывается и работает, но стена и архив хранятся только в браузере посетителя, а фигурки и работы берутся из файла `data/demo.json`. Демо-карточки помечены наклейкой «demo».

**Рабочий режим.** После подключения бесплатной базы Supabase (инструкция ниже, около 15 минут) стена становится общей для всех, архив сохраняется навсегда, а фигурки, работы, стикеры и вопросы дня редактируются прямо на сайте.

## Как подключить базу (один раз)

1. **Создай проект.** Зайди на [supabase.com](https://supabase.com), войди через GitHub, нажми *New project*. Регион выбери поближе, например *Central EU (Frankfurt)*. Придумай пароль базы и сохрани его.
2. **Создай таблицы.** В проекте открой *SQL Editor* → *New query*. Скопируй сюда весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажми *Run*. Должно появиться *Success*. Скрипт можно запускать повторно, он ничего не сломает.
3. **Разреши гостям оставлять следы без регистрации.** *Authentication* → *Sign In / Providers* → включи **Allow anonymous sign-ins** → *Save*. Для защиты от ботов там же можно включить CAPTCHA.
4. **Сделай себя администратором.** *Authentication* → *Users* → *Add user* → *Create new user*: введи свою почту и пароль, отметь *Auto Confirm User*. Затем снова открой *SQL Editor* и выполни, подставив свою почту:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'твоя@почта';
   ```
5. **Свяжи сайт с базой.** *Project Settings* → *API* (или *Data API*): скопируй **Project URL** и ключ **anon public**. На GitHub открой файл [`js/config.js`](js/config.js), нажми карандаш ✏️ и вставь значения:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
   Нажми *Commit changes*. Ключ anon — публичный, его можно хранить в открытом репозитории: доступ защищён правилами в базе.
6. **Проверь.** Через пару минут открой сайт → панель снизу → значок студии → *Studio admin* и войди своей почтой и паролем. Демо-баннер на стене пропадёт.

После подключения на полке и в портфолио будут те же демо-работы. Удали их или замени своими в режиме «Студия» на страницах Little Objects и My Stuff.

### Часовой пояс студии

Стена меняется в полночь по одному поясу для всех (сейчас `Europe/Moscow`). Чтобы поменять пояс, измени его в двух местах: в админке (*Настройки* → *Часовой пояс*) и в `js/config.js` (`TIMEZONE`).

### Защита от спама и правила

- Публиковать можно без регистрации: каждый посетитель получает гостевую сессию и может менять только свои элементы и только сегодня.
- Не больше 6 публикаций в минуту и 40 в день на гостя. Текст записки ограничен 280 символами.
- Картинки на стене до 2 МБ, только PNG, JPEG и WebP (браузер уменьшает их заранее).
- После трёх жалоб элемент скрывается сам и ждёт решения в *Studio admin* → *Модерация*.
- Прошлые дни доступны только для просмотра, но администратор может удалить из архива что угодно.

## Публикация на GitHub Pages

Сайт не требует сборки, GitHub раздаёт файлы как есть. *Settings* → *Pages* → *Build and deployment* → *Deploy from a branch* → ветка `main`, папка `/ (root)` → *Save*. Каждое изменение в `main` появляется на сайте через 1–2 минуты.

Камере нужен https, и на GitHub Pages он есть.

## Как устроено

- Чистые HTML, CSS и JavaScript-модули, без сборки и зависимостей. Клиент Supabase подгружается с CDN только в рабочем режиме.
- `index.html`: каркас; `css/`: стили по разделам (`base.css` — дизайн-система); `js/views/`: разделы; `js/store.js`: работа с данными (демо и Supabase); `js/booth-gl.js`: шейдеры фильтров; `js/booth-strip.js`: рамки; `js/game/levels.js`: уровни игры; `supabase/schema.sql`: база, правила доступа и хранилище.
- Цвета и шрифты: кобальт `#244EE7`, жёлтый, красный, нежно-голубой, розовый; шрифты Dela Gothic One, Golos Text, Caveat, Press Start 2P (Google Fonts).
