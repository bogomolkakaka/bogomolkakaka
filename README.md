# bogomolka — маленькая интернет-студия

Интерактивный сайт графического дизайнера: рабочий стол с предметами, фотобудка, общая стена дня, архив-календарь, игра про жизнь дизайнера, коллекция фигурок, видеопрокат с советами фильмов и портфолио. Весь интерфейс на русском.

Адрес сайта на GitHub Pages: **https://bogomolkakaka.github.io/bogomolkakaka/**

## Что внутри

| Раздел | Что умеет |
|---|---|
| **Рабочий стол** (главная) | Предметы на синем коврике ведут в разделы, их можно двигать мышкой (место запоминается). Живое превью сегодняшней стены, календарь с настоящей датой, мини-игра на экране консоли, стопка видеокассет, записка со случайными фразами. |
| **Фотобудка** | Камера компьютера или телефона, 8 фильтров на WebGL в реальном времени (+ «без фильтра»), зеркало, переключение камер, отсчёт 3-2-1, четыре кадра, 6 рамок, стикеры и надписи (двигать, вращать, масштабировать), скачивание PNG, «Поделиться» на телефоне, пересъёмка, загрузка готовых фото, если камеры нет, публикация на стену. Фото не покидают браузер, пока человек сам не нажмёт «Повесить на стену дня». |
| **Стена дня** | Общий холст: записки разных цветов, анонимные «шёпоты», рисование тремя кистями, стикеры, картинки, фотоленты, медали из игры. Свои элементы можно двигать, вращать, масштабировать и удалять (и мышкой, и с клавиатуры). Вопрос дня. Новые элементы появляются у всех без перезагрузки. Кнопка «пожаловаться». В полночь по времени студии стена уходит в архив и открывается новая. |
| **Капсула времени** | Календарь: у каждого дня маленькое превью коллажа. Переключение месяцев и лет, архивные стены открываются только для просмотра. |
| **Забег дизайнера** | Платформер на canvas: 3 уровня (БРИФ, ДЕДЛАЙН, FINAL FINAL V7), монетки, правки клиентов (их можно лопать прыжком сверху), 6 навыков с эффектами, 3 жизни, чекпоинты, экран проигрыша и перезапуск, экран победы и медаль на стену. Клавиатура и сенсорные кнопки, звук выключается в панели снизу. |
| **Маленькие объекты** | Полка с фигурками, ценники со статусами, вторая фотография при наведении, карточка с галереей, цветами и деталями, запрос на покупку. Редактирование в режиме «Студия». |
| **Видеопрокат** | Полка с видеокассетами: каждая — совет фильма или сериала с годом, жанром, парой слов «почему стоит посмотреть» и до трёх ссылок на просмотр. Обложки кассет рисуются автоматически в цветах сайта. Фильтры «Фильмы / Сериалы» и «От хозяйки / От гостей». Посоветовать может любой гость, но его кассета появится на полке только после одобрения в админке. Твои советы публикуются сразу с наклейкой «Хозяйка советует». |
| **Мои работы** | Разбросанные постеры, развороты, полароиды и папки по категориям, отдельная страница проекта. Редактирование в режиме «Студия». |
| **Студия (админка)** | Вход для хозяйки, модерация стены (жалобы, скрыть/удалить, любой день), проверка советов фильмов (одобрить/отклонить, жалобы), вопросы дня, свои стикеры, включение рамок фотобудки, контакты и часовой пояс. |

Пасхалки: наберите на клавиатуре `kerning` или ↑ ↑ ↓ ↓ ← → ← → B A. И постучите по полке с фигурками.

## Два режима работы

**Демо-режим** включается сам, пока база не подключена. Всё открывается и работает, но стена и архив хранятся только в браузере посетителя, а фигурки и работы берутся из файла `data/demo.json`. Демо-карточки помечены наклейкой «демо». Советы фильмов, которые гость отправил в демо-режиме, видит только он сам.

**Рабочий режим.** После подключения бесплатной базы Supabase (инструкция ниже, около 15 минут) стена становится общей для всех, архив сохраняется навсегда, а фигурки, работы, стикеры и вопросы дня редактируются прямо на сайте.

## Как подключить базу (один раз)

1. **Создай проект.** Зайди на [supabase.com](https://supabase.com), войди через GitHub, нажми *New project*. Регион выбери поближе, например *Central EU (Frankfurt)*. Придумай пароль базы и сохрани его.
2. **Создай таблицы.** В проекте открой *SQL Editor* → *New query*. Скопируй сюда весь файл [`supabase/schema.sql`](supabase/schema.sql) и нажми *Run*. Должно появиться *Success*. Скрипт можно запускать повторно, он ничего не сломает.
3. **Разреши гостям оставлять следы без регистрации.** *Authentication* → *Sign In / Providers* → включи **Allow anonymous sign-ins** → *Save*. Для защиты от ботов там же можно включить CAPTCHA.
4. **Сделай себя администратором.** *Authentication* → *Users* → *Add user* → *Create new user*: введи свою почту и пароль, отметь *Auto Confirm User*. Затем снова открой *SQL Editor* и выполни, подставив свою почту:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'твоя@почта';
   ```
5. **Свяжи сайт с базой.** *Project Settings* → *API* (или *Data API*): скопируй **Project URL** и ключ **anon public**. На GitHub открой файл [`js/config.js`](js/config.js), нажми карандаш ✏️ и вставь значения:
   ```js
   SUPABASE_URL: 'https://xxxxxxxx.supabase.co',
   SUPABASE_ANON_KEY: 'eyJhbGciOi...',
   ```
   Нажми *Commit changes*. Ключ anon — публичный, его можно хранить в открытом репозитории: доступ защищён правилами в базе.
6. **Проверь.** Через пару минут открой сайт → панель снизу → значок студии → *Студия* и войди своей почтой и паролем. Демо-баннер на стене пропадёт.

После подключения на полке и в портфолио будут те же демо-работы. Удали их или замени своими в режиме «Студия» на страницах «Маленькие объекты» и «Мои работы». Видеопрокат в рабочем режиме начинается пустым: добавь первые советы кнопкой «Добавить свой совет».

### Часовой пояс студии

Стена меняется в полночь по одному поясу для всех (сейчас `Europe/Moscow`). Чтобы поменять пояс, измени его в двух местах: в админке (*Настройки* → *Часовой пояс*) и в `js/config.js` (`TIMEZONE`).

### Защита от спама и правила

- Публиковать можно без регистрации: каждый посетитель получает гостевую сессию и может менять только свои элементы и только сегодня.
- Не больше 6 публикаций в минуту и 40 в день на гостя. Текст записки ограничен 280 символами.
- Картинки на стене до 2 МБ, только PNG, JPEG и WebP (браузер уменьшает их заранее).
- После трёх жалоб элемент скрывается сам и ждёт решения в *Студия* → *Модерация*.
- Советы фильмов от гостей всегда попадают в очередь *Студия* → *Видеопрокат* и видны всем только после твоего одобрения. Не больше 3 советов за 10 минут и 10 в день на гостя. Ссылки принимаются только вида `https://…` или `http://…`, до трёх на совет, открываются в новой вкладке. После трёх жалоб одобренный совет гостя сам возвращается на проверку.
- Прошлые дни доступны только для просмотра, но администратор может удалить из архива что угодно.

### Если база уже была подключена раньше

Чтобы заработал Видеопрокат, ещё раз запусти весь файл [`supabase/schema.sql`](supabase/schema.sql) в *SQL Editor*. Он добавит таблицы для советов и ничего не удалит. Заодно обновятся стартовые вопросы дня, но только если таблица вопросов пустая.

## Публикация на GitHub Pages

Сайт не требует сборки, GitHub раздаёт файлы как есть. *Settings* → *Pages* → *Build and deployment* → *Deploy from a branch* → ветка `main`, папка `/ (root)` → *Save*. Каждое изменение в `main` появляется на сайте через 1–2 минуты.

Камере нужен https, и на GitHub Pages он есть.

## Как устроено

- Чистые HTML, CSS и JavaScript-модули, без сборки и зависимостей. Клиент Supabase подгружается с CDN только в рабочем режиме.
- `index.html`: каркас; `js/views/films.js` и `css/films.css`: видеопрокат; `css/`: стили по разделам (`base.css` — дизайн-система); `js/views/`: разделы; `js/store.js`: работа с данными (демо и Supabase); `js/booth-gl.js`: шейдеры фильтров; `js/booth-strip.js`: рамки; `js/game/levels.js`: уровни игры; `supabase/schema.sql`: база, правила доступа и хранилище.
- Цвета и шрифты: кобальт `#244EE7`, жёлтый, красный, нежно-голубой, розовый; шрифты Dela Gothic One, Golos Text, Caveat, Press Start 2P (Google Fonts).
